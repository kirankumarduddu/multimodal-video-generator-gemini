    Step 1

    Before you start

    mvg is a command-line tool that runs on your computer and calls Google models in your own Google Cloud project. This guide asks the questions, writes the config files and checks your setup. Nothing is sent anywhere except the Google API calls you start in steps 4 and 8, and the Google Fonts request for the brand preview in step 6.

    What you need

    • A Google Cloud project with billing enabled, where you have (or can get) the Vertex AI User role.
    • Python 3.10 or newer.
    • git.
    • The Google Cloud CLI (gcloud).
    • ffmpeg is bundled with the Python package (imageio-ffmpeg); nothing to install.

    Use it responsibly

    • Fictional people only. Cast descriptions must describe invented people. Never ask for a real or famous person's likeness, voice or name.
    • Your rights. Only add logos, screenshots, fonts and quotes you have the right to use. Quotes must be real and approved.
    • Facts. The story writer may only use the facts you list in the brief. Check every number on the cards before you publish.
    • Follow Google's Generative AI Prohibited Use Policy.

    Costs

    Every model call is billed by Google to your project at Vertex AI pricing. Brand cards are rendered on your computer and cost nothing. Images, voice and music are billed per request. Video usually costs the most, so it comes last, behind the approval gate, and only for the shots you approve. Consider a budget alert on the project.

    Step 2

    Clone and install

    Pick your system. The commands below update to match.

    • pip install -e . installs the mvg command (package mvgen) into the virtual environment.
    • playwright install chromium downloads the headless browser that renders brand cards.
    • If PowerShell blocks Activate.ps1, run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned once, then try again.
    • If python is not found, use python3.
    • Activate the virtual environment again in every new terminal before you run mvg.
    • No separate ffmpeg install: pip install -e . brings a bundled ffmpeg through imageio-ffmpeg.

    Create a project folder

    Each film lives in its own folder. mvg init creates studio.yaml, brand.yaml and brief.yaml; you will replace them with the files this guide makes.

    To start from the example film instead: . Every command also accepts -C DIR to point at a project folder from anywhere.

    Connect Google Cloud

    mvg uses Application Default Credentials (ADC): your own Google sign-in, stored by gcloud on your computer. No service account key is needed.

    The ID, not the name. Find it on the console home page.
    The account you sign in to gcloud with.
    Veo is served from a region; Gemini 3, TTS and Lyria use global.
    Leave empty to receive videos directly. Or my-bucket / gs://my-bucket/prefix for Veo to write there.

    Run these once

    CommandWhy
    gcloud auth loginSigns the gcloud CLI in as you.
    gcloud config set projectMakes your project the default for gcloud commands.
    gcloud services enable aiplatform.googleapis.comTurns on Vertex AI, which serves every model mvg uses. Needs permission to enable services (Owner, Editor or Service Usage Admin).
    gcloud auth application-default loginCreates the ADC credentials that mvg (the Python client) uses.
    gcloud auth application-default set-quota-projectBills API quota for ADC calls to your project. Without it some APIs refuse user credentials.
    add-iam-policy-bindingGrants you the two roles below. Only an Owner or IAM admin can run it.
    storage linesTurn on Cloud Storage and let you write to the bucket, because output.gcs_uri is set.

      Step 9

      Make the film

      Cards first, then video. Run these in order in your project folder. Each step skips outputs that already exist (use --force to remake), so you can stop and resume at any point. mvg run runs them all and stops at the approval gate.

      Step 10

      Troubleshooting and FAQ

      403 PERMISSION_DENIED

      Your account lacks a role in the project, or the quota project is not set. Check the project ID, then grant the roles (an Owner or IAM admin must run this):

      Then run mvg doctor again. Role changes can take a minute or two to apply.

      SERVICE_DISABLED / "API has not been used in project"

      Vertex AI is not enabled in the project:

      If you see the error for storage.googleapis.com, you set output.gcs_uri; enable Cloud Storage too or set it back to null.

      429 RESOURCE_EXHAUSTED

      You hit a rate limit or quota. Lower limits.parallel in studio.yaml (for example to 1) and run the same command again later. Finished outputs are skipped, so the step resumes where it stopped. Quotas are listed in the console under IAM & Admin › Quotas.

      404 model not found

      The model id is wrong, the model is in a different location, or your project has no access to a preview model. Veo is regional (for example us-central1); Gemini 3 models, TTS and Lyria use global. Check the ids in studio.yaml against the Vertex AI model list.

      ADC "quota project" warning

      Google client libraries warn when user credentials have no quota project. Set it, and make sure you have roles/serviceusage.serviceUsageConsumer:

      Output blocked by safety filters

      Images or video can be filtered. Rephrase the shot: describe invented people by age range, look and clothing, never a real or famous person, brand, logo or readable text. Avoid medical, violent or child-related detail that is not needed. If people are blocked, check the model's person_generation setting. Then re-run only that scene with --force and its id.

      Playwright browser missing

      mvg cards needs Chromium. Inside the activated virtual environment run playwright install chromium. On Linux you may also need playwright install-deps chromium.

      Fonts not loading on cards

      Card rendering loads Google Fonts by family name, which needs internet access. Check the spelling against fonts.google.com. Offline or with a custom font, put the file in brand/fonts/ and use heading: {family: MyFont, file: brand/fonts/MyFont.ttf} in brand.yaml.

      Change one scene and re-run only it

      Edit the scene in story.json, run mvg story check, then remake only that scene by passing its id with --force, for example:

      mvg keyframes s06-shelf --force
mvg review
mvg approve s06-shelf
mvg clips s06-shelf --force
mvg assemble

      For a card, mvg cards s04-how --force; for a changed voice line, mvg voice s04-how --force. To take back an approval: mvg approve --revoke s06-shelf.

      What does it cost?

      All generation is billed by Google to your project; see Vertex AI pricing. mvg plan lists what will be generated (number of stills, keyframes, clip seconds, voice lines, music segments) so you can estimate before you run. Cards and the animatic are made on your computer; mvg cards --posters checks your branding in seconds, and the draft cut uses placeholder voice and music. Paid video is generated only for approved shots, and existing outputs are never regenerated without --force.

      Is my data sent anywhere else?

      No. There is no backend. mvg talks only to the providers you configure (Google Cloud, and your story LLM if it is not Gemini). This site saves your answers in your browser's localStorage; tokens and keys are never saved. Use Start over in the sidebar to clear it.
