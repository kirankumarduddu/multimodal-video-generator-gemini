What I build

I build AI agents that do real work in healthcare operations, and the harness around them that makes that work safe: the tools an agent may call, whose data it may see, the checks every answer passes, and the approval a person gives before anything is sent or saved.

Healthcare AI

AI coworkers for the people who run care: answers that reach across scheduling, CRM and workspace systems, proactive alerts and briefs, with each person's scope enforced on every request.

Agent harnesses

The engineering that turns a model into a dependable agent: tool contracts, read-only by default, fail-closed access, grounding checks on every number, human approval for every write, and monitoring of every turn.

Multimodal generation

Gemini, Veo, Lyria and text-to-speech pipelines that stay on brand: deterministic cards for every word and number, reference stills for a consistent cast, and an approval gate before the expensive step.

How I build agents

  • Cheap, checked work first. Do the deterministic, reviewable part before the expensive or irreversible part.
  • A person at every gate. Nothing that costs money, changes a record or reaches a customer happens without an approval.
  • Fail closed. An unknown user, a missing permission or an unreadable source means no answer, not a guess.
  • Every number has a source. Answers are checked against the tool results that produced them.
  • Tool output is data, never instructions. What an agent reads cannot change what it is allowed to do.
  • Measure it in production. Every turn is logged, rated and reviewed, so the agent gets better every week.

This project is that harness applied to video. Brand cards, cast stills and keyframes come first and are reviewed; a person approves each shot; only then does Veo or Gemini Omni generate the footage. See how it works.
