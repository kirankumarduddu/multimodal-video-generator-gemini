How it works

Cards first, then video. Cheap, exact assets are made and reviewed first. Video, the expensive part, is generated only for the shots you approve.

Each stage, and the model behind it

Every step is a command, and every step is idempotent: it skips outputs that already exist unless you pass --force. You can stop anywhere and pick up later.

1Brief and brand

brief.yaml · brand.yaml

You answer plain questions: purpose, audience, length, facts you can stand behind, colors, fonts, look and voice. The guide writes the files.

2Story

any LLM → story.json

Gemini, any OpenAI-compatible endpoint, Anthropic, or copy-paste into any chat app. The reply must match the story schema: scenes, cast, voice lines and music cues.

3Brand cards free

HTML → MP4 · Playwright · 24 fps

Titles, lists, stats, quotes, flows, screens and the end card, rendered frame by frame in your exact colors, fonts and logo. Captions too. mvg cards --posters renders one still per card in seconds to check your branding first.

4Cast stills

Nano Banana Pro · gemini-3-pro-image

One reference still per invented person, so the same face and clothes appear in every shot.

5Keyframes

Nano Banana Pro · gemini-3-pro-image

The first frame of each live-action shot, in the brand look, using the cast stills.

6Review and approve gate

mvg review · mvg approve

build/review.html shows every card, still, keyframe and the exact prompts. mvg clips --animatic turns keyframes into free Ken Burns moves; with placeholder voice and music, mvg assemble writes a draft cut to time the whole film.

7Video clips billed

Veo · veo-3.1-generate-001 (us-central1)
or Gemini Omni · gemini-omni-1.1-flash-preview (global, Interactions API)

Animates each approved keyframe. Unapproved shots are never sent.

8Voice and music

gemini-3.1-flash-tts-preview · lyria-3-pro-preview

Gemini TTS reads each line in the brand voice. Lyria scores each chapter from an instrumental brief.

9Assemble

ffmpeg

0.4 s crossfades, captions, voice placed per scene, music fitted per chapter and ducked under the voice by sidechain compression, loudness normalised to -16 LUFS. A 1080p master plus 720p web and phone copies.

Why cards first

Cost

Cards, cast stills and keyframes are cheap or free and fast to redo. Video is the expensive step, so it comes last and only for approved shots. The draft cut (animatic plus placeholder voice and music) lets you time the whole film before you pay for any video.

Brand accuracy

Words, numbers and logos are typeset from HTML in your fonts and colors, so they are always spelled and placed exactly. A video model never has to draw your logo.

No text in AI footage

Generated shots contain no readable text, logos, user interfaces or real people. Words live only on cards. That avoids garbled lettering and keeps product claims under your control.

A consistent cast

Each fictional person gets one reference still, and every keyframe is made from it. You approve faces and settings as stills, where changes are cheap, before they move.

Your project, your keys

  • No backend. mvg runs on your computer. It talks only to Google Cloud in your project and, if you choose one, your story LLM provider.
  • Your own sign-in. Google calls use Application Default Credentials from gcloud. Other providers' API keys are read from environment variables, never from files.
  • Your bill. All generation is billed by Google to your project. See Vertex AI pricing.
  • Checked before you spend. mvg doctor checks auth, the quota project, the API, your IAM permission and every model.

This website

The site is static: no backend, no analytics, no third-party scripts. The guide saves your answers in your browser's localStorage. Its optional connection test keeps your access token in the tab's memory only and sends it only to Google APIs. Reloading the page forgets it.

The only other outside request is Google Fonts, to preview your brand fonts in step 6.

Quick start

The guided setup explains each line and writes your config files.

git clone https://github.com/kirankumarduddu/multimodal-video-generator-gemini.git
cd multimodal-video-generator-gemini
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # Windows; macOS/Linux: source .venv/bin/activate
pip install -e .
playwright install chromium
mvg init my-film --example kettle-and-kite
cd my-film                          # then set gcp.project in studio.yaml
mvg doctor
mvg run                             # stops at the approval gate

For LLM agents

Coding agents can drive mvg end to end. Start with:

  • AGENTS.md: how to set up, run and change the project (CLAUDE.md for Claude Code).
  • README.md: overview, install and usage.
  • llms.txt: a short map of the project and its docs for LLMs.
  • story.schema.json and story_prompt.md: the story contract and the prompt the CLI uses.

Keep a person at the gate. Agents should stop after mvg review and let a person open build/review.html and run mvg approve before any paid video is generated.
